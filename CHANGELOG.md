# Changelog

No releases have been cut from this fork yet, and nothing here publishes to a registry.

There is no per-change changelog. **What changed** is git history — commit messages in this
repository are written as full entries, with the reasoning and the verification in the body.
**What is true** is the spec graph, rooted at [`SPEC.md`](SPEC.md): a change that alters a boundary,
a contract or a decision updates the owning spec in the same commit.

When a release is eventually cut, its notes are assembled from git history at that point, and land
here as one line per release.

This repo hard-forked PenguinHarness at its 0.2.2 baseline (`d14be6f`). Upstream release history
(0.0.1 – 0.2.2) was removed from the tree and survives only in git history.
