# Hard fork: stop merging PenguinHarness

travel-agent is no longer a downstream of penguin-harness. The engine stays at the 0.2.2 snapshot plus local patches; we do not keep the tree merge-clean for an upstream we never pull.

Existing `default_agent` instances now pick up library skills added after they were created (the `penguin-browser` miss that left the model on Playwright). Already-installed skill directories are not overwritten.
