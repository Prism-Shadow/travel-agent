Getting Started with Penguin Browser

Connect Travel Agent or a local Playwright CLI to task tabs in your Chrome profile.

Installation

1
Pin the extension

Click the puzzle icon in Chrome's toolbar, then pin Penguin Browser so it's always visible.

2
Choose how to connect

In Travel Agent, select “My own Chrome (extension)” in the right-side Browser menu. The agent may create its own task tabs.

3
Authorize an existing tab only when needed

To let the agent use a tab you already opened, click the extension icon on that tab. It joins the cyan Penguin Browser group.

4
Standalone development 
# from the travel-agent checkout
pnpm install
pnpm build
penguin-browser session new
penguin-browser -s 1 -e "await page.goto('https://example.com')"

CLI Examples

# create a stateful sandbox, outputs session id (e.g. 1)
penguin-browser session new
# navigate to a URL
penguin-browser -s 1 -e "await page.goto('https://example.com')"
# get the accessibility tree of the page
penguin-browser -s 1 -e "console.log(await snapshot({ page }))"
# click an element by its accessibility reference
penguin-browser -s 1 -e "await page.locator('aria-ref=e5').click()"

How It Works

  • No new Chrome instances: Works with your current browser session
  • No CDP mode required: No need to restart Chrome with special flags
  • Full CDP access: Complete Chrome DevTools Protocol capabilities
  • Visual feedback: Extension icon changes color to indicate connection status

Icon States

  • Gray: Not connected to any tab
  • Cyan/light blue group: Successfully connected and ready
  • Orange badge (...): Connecting to relay server
  • Red badge (!): Error occurred

Privacy & Security

Penguin Browser MCP runs locally in your browser and does not send any data to external servers. All browser control happens through the standard Chrome DevTools Protocol on your machine.

MCP Setup (Optional)

The CLI is the recommended way to use Penguin Browser. To start the local stdio MCP server:

penguin-browser

For full editor configuration, open MCP.md in the travel-agent checkout.
